# HDR-9000 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (\`- [ ]\`) syntax for tracking.

**Goal:** Add an isolated HDR-9000 XML tracking and HIS synchronization workflow without changing KR-800 behavior.

**Architecture:** New HDR parser, revision store, processor, and watcher operate independently from KR-800 pairing. The implementation reuses only app configuration, HIS authentication/request conventions, generic device-folder commands, and redacted application logging.

**Tech Stack:** Rust 2021, Tauri v2, rusqlite, roxmltree, serde_json, reqwest, React 19, TypeScript, Vite.

## Global Constraints

- Preserve all KR-800 command, database, pairing, event, and endpoint behavior.
- HDR-9000 uses device key hdr-9000, a separate runtime, queue, persistence tables, and hdr9000:* events.
- Index only stable XML whose trimmed Product_Model is HDR-9000; revalidate the snapshot before sending.
- Filename stem is maHoSo. Patient_ID is reconciliation metadata only.
- Index each file_path + content_hash revision and persist the parsed sparse snapshot immediately.
- Filter date: filesystem creation, valid Measurement_Date, filesystem modification, discovery. Source order: creation, modification, discovery, revision ID.
- Do not pair HDR records, load dm_thi_luc.json, serialize nulls, or insert implicit zeroes.
- Filter stale fields before every send/retry; an empty payload becomes superseded without a HIS request.
- Never install/run Cargo/Rust or a Tauri build. Add Rust test source only.

~~~rust
pub fn parse_hdr9000_xml(bytes: &[u8], file_name: &str) -> Result<ParsedHdr9000, Hdr9000ParseError> {
    let xml = decode_xml(bytes)?;
    let document = roxmltree::Document::parse(&xml).map_err(Hdr9000ParseError::Xml)?;
    let model = text_by_tag(&document, "Product_Model").unwrap_or_default();
    if model.trim() != "HDR-9000" { return Err(Hdr9000ParseError::WrongModel(model)); }
    let ma_ho_so = Path::new(file_name).file_stem().and_then(|s| s.to_str())
        .unwrap_or_default().trim().to_owned();
    if ma_ho_so.is_empty() { return Err(Hdr9000ParseError::MissingFileStem); }
    Ok(ParsedHdr9000 {
        ma_ho_so, patient_id: optional_text(&document, "Patient_ID"),
        measurement_date: parse_measurement_date(optional_text(&document, "Measurement_Date")),
        payload: build_sparse_payload(&document)?,
    })
}
~~~

Read only the approved FAR/NEAR/PD tags. Accept valid JSON numbers for SPH/CYL/Axis/VA/ADD, retain PD as trim-preserved string, and omit absent/empty/invalid values and objects.

- [ ] **Step 3: Implement transactional success/version update**

~~~rust
pub fn finish_success(db: &AppDb, id: i64, response: &str, owner: &str) -> Result<(), String> {
    let mut conn = lock_conn(db)?;
    let tx = conn.transaction().map_err(|e| e.to_string())?;
    let revision = load_claimed_revision(&tx, id, owner)?;
    for (path, _) in leaf_fields(&revision.request_payload()?) {
        tx.execute("INSERT INTO hdr9000_field_versions (ma_ho_so,field_path,revision_id,source_time,created_at)
          VALUES (?1,?2,?3,?4,datetime('now')) ON CONFLICT(ma_ho_so,field_path) DO UPDATE SET
          revision_id=excluded.revision_id,source_time=excluded.source_time,created_at=excluded.created_at",
          params![revision.ma_ho_so, path, id, revision.source_time])?;
    }
    tx.execute("UPDATE hdr9000_revisions SET status='processed',response_payload=?1,
      processed_at=datetime('now'),updated_at=datetime('now') WHERE id=?2 AND sending_owner_id=?3",
      params![response, id, owner])?;
    tx.commit().map_err(|e| e.to_string())
}
~~~

Compare versions by (source_time, id), and recursively rebuild objects after stale leaf removal.

~~~rust
pub fn index_path(db: &AppDb, path: &Path, min_age: Duration) -> Result<IndexOutcome, String> {
    if !has_xml_extension(path) || !file_is_stable(path, min_age) { return Ok(IndexOutcome::SkippedUnstable); }
    let discovered_at = now_local();
    let meta = fs::metadata(path).map_err(|e| format!("metadata {}: {e}", path.display()))?;
    let bytes = fs::read(path).map_err(|e| format!("read {}: {e}", path.display()))?;
    let parsed = match parse_hdr9000_xml(&bytes, file_name(path)?) {
        Ok(value) => value,
        Err(Hdr9000ParseError::WrongModel(model)) => return Ok(IndexOutcome::SkippedModel(model)),
        Err(error) => return Ok(IndexOutcome::XmlError(error.to_string())),
    };
    let dates = resolve_dates(meta.created().ok(), parsed.measurement_date, meta.modified().ok(), discovered_at)?;
    insert_revision_if_new(db, RevisionDraft::from_snapshot(path, &bytes, parsed, dates))
}
~~~

Use this exact function for initial scan, rescan, polling, and notify callbacks. Log model/file/maHoSo/hash prefix/source time and never queue a rejected model. Persist a malformed HDR XML as xml_error only when its model can be established; unparseable XML is logged and skipped.

~~~rust
async fn process_revision(...) -> Result<FileOutcome, String> {
    if !claim_revision(db, revision_id, &state.instance_id)? { return Ok(FileOutcome::default()); }
    let revision = load_revision(db, revision_id)?.ok_or("missing revision")?;
    validate_snapshot_model(&revision)?;
    let payload = filter_stale_fields(db, revision.id, revision.snapshot_payload()?)?;
    if payload.as_object().is_some_and(|fields| fields.is_empty()) {
        mark_superseded(db, revision.id, &state.instance_id)?;
        return Ok(FileOutcome::skipped());
    }
    let dv_kham_id = resolve_or_reuse_service_id(...).await?;
    save_request(db, revision.id, dv_kham_id, &payload.to_string(), &state.instance_id)?;
    let response = send_sparse_update(..., dv_kham_id, &payload).await?;
    finish_success(db, revision.id, &response, &state.instance_id)?;
    Ok(FileOutcome::processed())
}
~~~

Serialize revisions by a HashMap lock keyed only by maHoSo. Recover expired leases at startup and periodic intervals. Map errors to patient_not_found, service_not_found, send_error, xml_error, no_supported_data, duplicate, or superseded; no HDR transition may produce awaiting_pair.
